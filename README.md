# 🚀 ERP System (Backend)

## 📌 Overview

This is a backend-based **ERP (Enterprise Resource Planning) System** built using **Spring Boot and Maven**.
It is designed to manage and streamline business operations like employee management, data handling, and system workflows.

---

## 🛠️ Tech Stack

* Java ☕
* Spring Boot 🚀
* Maven 📦
* REST APIs 🔗

---

## ⚙️ Features

* Backend architecture using Spring Boot
* RESTful API structure
* Scalable and modular code design
* Maven-based project setup

---

## 📂 Project Structure

* `src/` → Main source code
* `.mvn/` → Maven wrapper files
* `pom.xml` → Project dependencies
* `mvnw` → Maven execution script

---

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/SubhanshuPratapSingh/erp-system.git
   ```

2. Navigate to project:

   ```bash
   cd erp-system
   ```

3. Run the project:

   ```bash
   ./mvnw spring-boot:run
   ```
